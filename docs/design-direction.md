# 디자인 방향

> 작성일: 2026-10-20
> 대상: minimoku 전체 UI. 목적은 프런트엔드 포트폴리오로서 "템플릿 기본값처럼 보이지 않는" 인상.
> 전제: 디자인 토큰(`globals.css`)과 Pretendard 는 정비 완료.

---

## 출발점: 이 앱은 무엇인가

LinkLocker 는 "나중에 읽을 것들의 더미", PigMoney 는 "하루하루 드나든 돈". 둘 다
**시간 축에 쌓이는 개인 기록**이다. 공통 성격은 대시보드가 아니라 **장부**다.

그래서 시각 재료는 장식이 아니라 데이터 자신이다 — 금액, 날짜, 도메인. 겉치레(카드 껍데기,
동일한 그림자)를 걷어내고 데이터에 무게를 준다.

## 버리는 것

현재 화면의 인상은 **"회색 배경 위에 흰 카드가 반복"** 이다. 항목마다 같은 radius, 같은
연회색 그림자, 같은 패딩. 이것은 가장 흔한 기본값이고, 지금 촌스러움의 주된 원인이다.

- 회색 면으로 영역을 나누는 방식 → **선과 여백**으로
- 항목마다 카드 → **행(row)** 으로. 띄움(elevation)은 실제로 떠 있는 것(모달·드로어)에만
- 하드코딩 색 112회 → 토큰으로

## 색 — 두 개의 방, 두 개의 조명

| 이름 | 라이트 | 다크 | 역할 |
|---|---|---|---|
| paper | `#ffffff` | `#1e2939` | 캔버스. 콘텐츠 영역에 회색 면을 깔지 않는다 |
| ink | `#1f2733` | `#e8eaee` | 본문. 기존(#364153)보다 진하게 — 글자에 무게를 준다 |
| ink-soft | `#6a7282` | `#9ca3af` | 보조 정보 |
| rule | `#e7e9ee` | `#2f3a4a` | 머리카락 선. 면이 아니라 선으로만 구분 |
| linklocker | `#2b7fff` | 동일 | LinkLocker 강조 |
| pigmoney | `#ec4899` | `#f472b6` | PigMoney 강조 |

**화면에서 채도를 가진 것은 그 서비스의 강조색 하나뿐**이다. 서비스마다 조명색이 다른 두 개의 방.
이미 있던 자산(파랑/핑크)을 버리지 않고 역할을 분명히 한 것이다.

## 타이포 — 한 가족, 굵기로 위계

Pretendard 가변(45~920) 한 가족만 쓴다. 두 번째 서체를 들이지 않고 **굵기와 자간**으로 위계를 만든다.

- **숫자가 타이포그래피다.** 금액·합계는 `tabular-nums`, 굵기 600~700, 우측 정렬.
  자릿수가 흔들리지 않아야 장부로 읽힌다. (분위기용 모노스페이스 서체는 쓰지 않는다)
- 날짜 머리: 날짜를 큰 숫자로, 요일을 작게 곁들인다
- 라벨은 문장 그대로. **대문자 + 자간 벌린 라벨(eyebrow)은 쓰지 않는다**

## 레이아웃 — 장부

```
10월 20일  월                                      −15,500
   점심 — 김치찌개            식비                 −11,000
   아메리카노                 카페                  −4,500
─────────────────────────────────────────────────────────
10월 19일  일                                      −39,500
   저녁 약속                  식비                 −34,000
```

- 좌측 정렬이 기본, **금액만 우측 정렬**
- 행 사이는 넉넉한 높이 + 머리카락 선. 카드와 그림자는 없다
- 하루 소계를 날짜 머리 오른쪽에 둔다 — 구분선이 "날짜가 바뀌었다"는 정보를 인코딩한다

LinkLocker 도 같은 장부 골격을 쓰되, 링크는 시각적 변별이 필요하므로 **폴더 색 스파인**으로
소속을 인코딩한다 (16개가 모두 같은 회색 썸네일인 현재 상태를 대체).

## 원칙

1. **내용이 구조다** — 카드 껍데기를 걷고 선과 여백으로 구분한다
2. **숫자가 타이포그래피다** — 금액은 크게, 고정폭 숫자로, 오른쪽에
3. **채도는 강조색에만** — 나머지는 먹과 종이
4. **모션은 사용자 행동에만** — 드로어·모달·행 확장. 스크롤 등장 효과는 쓰지 않는다

## 대담함을 쓰는 곳

**금액 타이포그래피 한 곳.** 큰 tabular 숫자로 장부의 인상을 만들고, 주변은 전부 조용하게 둔다.

## 피한 기본값 (자기 점검)

- 크림 배경 + 세리프 디스플레이 + 테라코타 강조 — 쓰지 않음
- 니어블랙 + 애시드 그린/버밀리언 — 쓰지 않음
- 신문 조판(머리카락 선 + radius 0 + 조밀 컬럼) — 선은 쓰되 **행 경계라는 정보**로 쓰고,
  radius 는 실제로 떠 있는 것에 유지, 행 높이는 넉넉히 둔다
- 동일 radius·동일 그림자 카드 키트 — **현재 상태이며, 버리는 대상**
- 대문자 eyebrow 라벨 / 가운뎃점으로 이은 메타 문자열 / 버튼 끝의 `→` / 작은 라벨용 모노스페이스 — 쓰지 않음

## 작업 순서

1. PigMoney 쓰기 화면 (파일럿) — 조회/입력 분리 + 장부 레이아웃 + 금액 타이포
2. PigMoney 보고서·달력
3. LinkLocker 목록·카드
4. 하드코딩 색 112회 토큰화
5. 홈 — 위 화면들이 정리된 뒤에 캡처해서 싣는다
